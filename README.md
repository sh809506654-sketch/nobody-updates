# NOBODY · Моя робота - оновлення

Тут публікуються готові версії програми «NOBODY · Моя робота» для Mac з чипом Apple (arm64).
Вихідного коду програми тут немає - лише релізи і скрипти для їх публікації.

## Як програма оновлюється

Починаючи з версії 1.0.3, кнопка «Оновити програму»:

1. Читає `latest.json` з останнього релізу:
   `https://github.com/sh809506654-sketch/nobody-updates/releases/latest/download/latest.json`
2. Якщо там новіша версія - показує, що нового, і питає дозволу.
3. Завантажує zip із релізу і перевіряє розмір і sha256 з `latest.json`.
4. Робить резервну копію всіх даних. Якщо копія не вдалася - оновлення скасовується.
5. Закривається, ставить нову версію на місце старої і відкривається знову.
   Якщо нова версія не запустилась, повертається попередня.

З версії 1.0.5 є швидке оновлення: у релізі поруч із повним zip лежить маленький
`NOBODY-app-<версія>.zip` (лише код програми, тека `app/`, кілька сотень КБ). Якщо версія Electron
у програмі збігається з полем `appOnly.electron`, кнопка завантажує тільки його і замінює
`Contents/Resources/app` (з тією ж резервною копією, збереженням попередньої версії і відкатом).
Якщо щось не так - програма сама бере повний zip. Версії до 1.0.5 поле `appOnly` ігнорують.

Версії 1.0.1 і 1.0.2 так не вміють: 1.0.3 треба один раз встановити вручну
(розпакувати zip і перетягнути NOBODY.app у теку Програми).

## Формат latest.json

```json
{
  "app": "NobodyWork",
  "version": "1.0.3",
  "arch": "arm64",
  "url": "https://github.com/sh809506654-sketch/nobody-updates/releases/download/v1.0.3/NOBODY-mac-1.0.3-apple-silicon.zip",
  "sha256": "<64 символи>",
  "size": 102133407,
  "notes": ["Що нового"],
  "appOnly": {
    "url": "https://github.com/sh809506654-sketch/nobody-updates/releases/download/v1.0.5/NOBODY-app-1.0.5.zip",
    "sha256": "<64 символи>",
    "size": 260000,
    "electron": "33.4.11",
    "minVersion": "1.0.5"
  }
}
```

`appOnly` необов'язкове. `scripts/release.sh` робить його сам (через `scripts/make-app-only.py`).

## Як опублікувати нову версію

1. Зберіть `NOBODY-mac-<версія>-apple-silicon.zip` (усередині `NOBODY.app` і «Як встановити.txt»).
   Версія в `package.json`, `js/version.js` та `Info.plist` має збігатися.
2. Запустіть:

```
scripts/release.sh NOBODY-mac-1.0.4-apple-silicon.zip 1.0.4 "Перший пункт; Другий пункт"
```

Скрипт порахує sha256 і розмір, створить `latest.json` і реліз `v1.0.4` з обома файлами,
позначеним як останній. Після цього кнопка «Оновити програму» в усіх копіях 1.0.3+ побачить нову версію.

Потрібні `node` і `gh` (`gh auth login`).

Не видаляйте старі релізи одразу: посилання з `latest.json` має лишатися робочим,
поки всі не оновляться.
